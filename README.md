## 🚀 How to Run Any Week

Each week folder contains its own `README.md` with specific instructions.
In general:

```bash

git clone https://github.com/<your-username>/flexisaf-ai-native-python-beginner.git
cd flexisaf-ai-native-python-beginner

# Navigate to a specific week
cd week-01-setup

# (If the week uses dependencies)
python -m venv venv

pip install -r requirements.txt

# Run the code
python <script_name>.py
