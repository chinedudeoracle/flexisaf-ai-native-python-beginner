## Deliverables

1. **Contact Book (`contact_book.py`)**
   - Uses a **Dictionary** to store contacts.
   - Uses a **List** to store multiple phone numbers per contact.
   - Uses a **Dictionary Comprehension** to sort and display the contacts.

2. **Student Scores (`student_scores.py`)**
   - Uses a **Tuple** to store fixed student info (Name, ID).
   - Uses a **List** to store the scores.
   - Uses a **List Comprehension** to filter passing scores (>= 50).

## How to Run

Run either script from the terminal:

```bash
python contact_book.py
python student_scores.py
